## JSON Super Heroes

#### Darstellung der Super Heroes

In dieser Übung soll es eine Darstellung der Super Heroes mit ihren Eigenschaften geben. Diese soll zum Ende der Übung wie auf der Abbildung [Heroes](./json-superheroes.png) aussehen. Dazu muss in dem [html-Dokument](./heroes.html) per Javascript das [JSON](https://mdn.github.io/learning-area/javascript/oojs/json/superheroes.json) geladen und verarbeitet werden. Das Styling dazu ist unter [styles.css](./style.css) zu finden.
